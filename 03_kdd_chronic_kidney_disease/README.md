# KDD: Chronic Kidney Disease Pattern Discovery

This project will follow Selection, Preprocessing, Transformation, Data Mining, and Interpretation/Evaluation using the Chronic Kidney Disease dataset.

The project will make the KDD stages explicit by documenting feature selection, mixed-type cleaning, missing-value treatment, scaling, optional PCA, classification, and unsupervised pattern discovery.

Raw data will be stored under `data/raw/` locally and excluded from Git.
